# nas-rclone Privacy Policy

nas-rclone is a personal tool used only by its owner. It accesses only the owner's own Google Drive. It reads and writes files in folders the owner chooses, for backups from the owner's home NAS.

No data is collected, sold, shared, or sent to any third party. OAuth tokens are stored only on the owner's NAS.

Google user data is used only to sync the owner's files, in line with the Google API Services User Data Policy, including its Limited Use requirements.
